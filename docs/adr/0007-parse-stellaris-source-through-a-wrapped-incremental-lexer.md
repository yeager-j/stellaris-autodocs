# Parse Stellaris source through a wrapped incremental lexer

Jomini is an accepted dependency for reading Paradox script, consumed through its `TokenReader` incremental lexer rather than its `TextTape`. The parser adapter converts that token stream into the application-owned parsed representation and is the only place a parser-library type appears. This choice is reversible at the cost of one module: nothing above the adapter names Jomini, and the representation is defined without reference to it.

The tape is not used because it cannot support source traceability or failure isolation, and because it is not correct enough on Stellaris source. It exposes no byte position for a brace or an operator, so a Source Excerpt cannot be bounded to a definition. It rejects real vanilla and mod files that use escaped scripted-constant arithmetic, bare token lists, and conditional-compilation blocks. Most seriously, it accepts a file whose braces do not balance and silently reparents everything after the unbalanced brace, which two vanilla files and one large mod trigger today; a wrong document with no diagnostic is worse for this application than a refused file. The [parser evaluation](../spikes/parser-evaluation.md) measured each of these against 7,938 files.

The adapter adds three things Jomini does not provide. It derives a byte range for every node by treating the reader's position before a token as a lower bound and skipping the trivia Clausewitz skips. It resynchronizes after a syntax fault at the next definition, which lost roughly one definition per detected fault in the spike rather than abandoning the file. And it recognizes the Stellaris dialect constructs the reader does not: `[[NAME] … ]` conditional compilation, `@\[ … ]` expressions, and `[Scope.GetName]` runtime references. Every derived range is verified by re-slicing it from the source and comparing it with the token it claims to cover; that check runs over the whole corpus, not only over fixtures.

Recovery is a heuristic about layout rather than a rule of the grammar, and it may misattribute nesting immediately around a fault. The application-owned `ParsedFile` therefore marks definitions before the first fault Clean and definitions emitted after resynchronization Recovered, while retaining the fault position and recovery boundary. `analysis` emits a visible file-scoped recovery issue but propagates incompleteness only from definitions the parser could not emit and from Recovered evidence, so earlier Clean facts remain usable. A stray token that leaves source syntactically valid remains undetectable; the parser evaluation records the shipped mod file that demonstrates it.

The two-adapter cross-check that produced this evidence is retained in the spike harness rather than in the application. Running Jomini's tape beside the wrapper over a real corpus is how every wrapper defect was found, and it remains the way to validate a change to the adapter or a Jomini upgrade.
